ساخت APK بدون نصب چیزی روی کامپیوتر:
1) در github.com یک ریپازیتوری خالی بساز (Private هم اوکی است).
2) محتوای همین پوشه را (با پوشه‌ی مخفی .github) آپلود کن: Add file > Upload files.
3) تب Actions > Build APK را ببین. بعد از ۴ تا ۶ دقیقه سبز می‌شود.
4) داخل همان اجرا، پایین صفحه در بخش Artifacts فایل FxCalc-apk را دانلود کن، زیپ را باز کن و app-debug.apk را روی گوشی نصب کن.
اگر Android Studio داری: Open پوشه > Build > Build APK(s).
